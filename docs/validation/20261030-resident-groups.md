## 検証
- 自動テスト21件合格: node --test tests/chat-core.test.mjs tests/chat-portraits.test.mjs tests/chat-resident-groups.test.mjs
- Chrome実画面: すべて33人、シミュラークル4人、大奥28人、神AIのみとら1人を確認。
- 「ひな」で検索し大奥を選ぶと、ひなた1人 / 28人。神AIへ切り替えると0人 / 1人。解除ボタンで検索空欄・すべて33人へ復帰。
- 矢印キーでワディーからひなひなへ、Endで萌神へ移動することを確認。
- 神AIからみとら、シミュラークルからひなひなを選び、対応する会話画面と立ち絵を確認。選択後の分類と「いま話している」の更新も確認。
- PC、390×844、844×390で目視確認。横向きでカード領域が28pxに潰れる症状を再現し、検索と分類を同じ段に配置して189pxへ修正。同条件でカード1段全体が見えることを確認。
- 分類切り替え後の人数・プレビュー更新が例外で止まる症状を実画面で再現し修正。4人と1人の人数・プレビューを同操作で再確認。
- 一時的なブラウザの画面寸法指定を解除。APIへの実送信・実機スマートフォン・公開配信は今回の検証対象外。

## 回帰確認手順
1. chat.html?persona=hina&mode=immersive の住人選択で3分類を順に押す。4・28・1人と、カードの所属・プレビュー・人数が一致すること。
