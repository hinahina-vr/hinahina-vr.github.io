## 実施して合格した検証
- Chromeの実画面で33人すべてを住人カードから選択し、対応する画像URLとデコード完了を待って確認。ひなた以外の32人ではひなたのキャンバスが非表示になることを確認。
- 31人の最終WebPを背景色に合成した一覧3枚を目視確認。外靴・欠けた手足・元の構図の単純なコピー・長身やリアル調が混ざっていないことを確認。座り姿の頭身は、立位へ換算したデザイン目標であり厳密な数値測定ではない。
- 31人すべての画像に透明部分と不透明部分があることをPillowで検証。RGBA WebPに変換。画像に再着色や骨格の後加工はしていない。
- PCの会話・住人選択、スマホ幅390×844の会話・性格設定、新ひなたの手振り・なでる笑顔を画面で確認。
- キーなしのおためし会話がえここ・ひなたで完了することを確認。APIキーは入力していない。
- 動きを抑える設定でフレーム番号が時間経過後も固定、しぐさ無効時も新しい静止画を表示。検証後はしぐさ有効・動きを抑える無効へ戻した。
- 横向き844×390でひなたが小さすぎる問題を再現。修正後は上半身を大きく表示。同じ寸法で顔と会話文を再確認。短い横画面では初期のおためし話題ボタンと重複する発話者名を隠し、会話文の領域を確保。
- 一時的なブラウザの画面寸法指定を解除。確認用Chromeタブを残した。
- 自動テスト: node --test tests/chat-core.test.mjs tests/chat-portraits.test.mjs — 18件合格。人格保持、追加設定、キー保存同意、OpenRouter直接接続、エラー処理、書き出し、33人の画像同梱、対象外2人のハッシュ、ひなた旧リグの混入防止を含む。
