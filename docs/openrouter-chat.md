# OpenRouterで住人と話す

サイトの利用者向けの操作と、更新する人向けの確認手順。

1. ホームの住人とおしゃべり、または住人紹介の各カードから開く。
2. 自分のOpenRouter APIキーを入力し、この接続設定を使うを押す。初期モデルはDeepSeek V4.1 Flash（`deepseek/deepseek-v4.1-flash`）。モデルは変更できる。
3. キーを残したい場合だけ、このブラウザにAPIキーを保存するにチェックする。

会話はブラウザから `https://openrouter.ai/api/v1/chat/completions` へ直接送る。サイトのサーバーを経由するチャットAPIは設けていない。利用料は入力したキーのアカウントにかかる。モデル一覧を取得すると、ブラウザからOpenRouterの `/api/v1/models` を呼ぶ。この取得にはAPIキーを送らない。

## 追加設定を人格ごとに保存する

話す相手を選び、この人格の追加設定を開く。好きな話題や会話の好みを入力し、この人格の設定を保存を押す。次の送信から使う。未保存の変更がある間は送信せず、保存を案内する。

基本設定は `characters/char_*.md` をそのまま使う。追加設定より基本設定を優先するよう、モデルへ指示する。基本設定の編集欄・プレビュー・書き出し機能は作っていない。会話の書き出しには、利用者と住人の発言と、その人格の追加設定だけを含める。

**クライアントだけで動かすため、基本設定を秘密にはできない。** ブラウザが取得するアセットとOpenRouterへの送信内容は開発者ツールから確認できる。モデルにも設定を会話へ出さないよう指示するが、返答による漏出を完全に防ぐものではない。

## APIキーや履歴を消す

APIキーの保存は初期状態ではオフ。チェックを付け、接続設定を使うを押した時に限り、`localStorage` に保存する。保存しない場合はページのメモリーと入力欄だけに保持し、再読み込みでも消える。ブラウザのパスワード管理機能への保存は行わない。

保存チェックを外すと保存済みのキーをすぐ削除する。APIキーを消すでは、入力中・使用中・保存済みのキーを消し、受信中の通信も中断する。キーを保存しているタブで削除すると、ほかの同一サイトのチャットタブにも反映する。

会話履歴の保存も初期状態ではオフ。保存を選んだ場合は人格ごとに直近80発言を保存し、通信には直近の会話を使う。受信を中断した返事や途中で失敗した返事は、次の送信や保存履歴に含めない。APIキーと基本設定は、会話履歴へ保存しない。

APIキーと会話は、保存したブラウザの同一サイトのスクリプトから読める。共有端末では保存チェックを付けずに使い、終わったらAPIキーを消す。

## 没入モードで話す

画面上部の没入モードを押すと、ブラウザ内いっぱいに相手の立ち絵と会話を表示する。ブラウザの上部はそのまま使える。全画面ボタンでは、対応するブラウザの全画面表示にも切り替えられる。

入力中や返事の到着に合わせてWebGLの光が変わる。これは文字の会話に応じた演出で、マイクの音声を聞いているものではない。没入モードではEnterで送信、Shift+Enterで改行。日本語変換中のEnterでは送信しない。通常表示のCtrl / ⌘ + Enterも使える。

相手ボタンで住人を検索・選択し、履歴ボタンで過去の発言を読む。設定ボタンからAPIキー・モデル・追加設定を変更できる。入力途中の文章と人格ごとの会話は、モードや相手を切り替えても保持する。パネルは閉じる、会話に戻る、Escで閉じられる。パネルを閉じた状態のEscは通常表示へ戻る。Ctrl / ⌘ + Kで相手を選び、入力欄の外で / を押すと入力欄へ移動する。

着せ替えボタンから、次の5種類を選べる。着せ替えは見た目だけを変え、基本人格や追加設定、会話には影響しない。

| 着せ替え | 見た目 |
| --- | --- |
| 桜のまどろみ（初期設定） | キャラの立ち絵と桜色の光、小さなハート |
| 星くずミルク | キャラの立ち絵と空色の光、小さな星 |
| ミントソーダ | キャラの立ち絵とミント色の泡 |
| はちみつ | キャラの立ち絵とはちみつ色の光 |
| 星影・ダーク | 暗い背景に浮かぶ粒子。最初の没入表示の雰囲気を残したもの |

初期背景は大奥の寝室。設定パネルの背景から、淡い光の背景にも切り替えられる。明るい4種類では選択中の人格の立ち絵を表示し、星影・ダークでは以前の粒子の表示を使う。33人にはそれぞれ別の立ち絵がある。読み込むのは選択中の相手の画像だけで、WebGLが使えない環境でも立ち絵と寝室を表示する。

着せ替え・背景・明るさ・光の動きを抑える設定は、このブラウザに保存する。OSで動きを減らす設定が有効なら、初期状態から動きを抑える。WebGLが利用できない場合も軽量表示で会話を続けられる。

## 人格を更新したらチャット用データも生成する

```sh
npm run build:chat
npm run test:chat
npm run test:chat-ui
npm run test:chat-immersive
npm run test:chat-art
npm run test:chat-bedroom
```

`build:chat` は住人紹介の33人を確認し、各人の既存設定から `assets/chat/catalog.json` と `assets/chat/personas/*.json` を生成する。元の設定ファイルは変更しない。公開はHTML・CSS・JavaScript・JSONの静的ファイルだけでよい。

ブラウザ試験はローカルページを実際に操作する。OpenRouterの返答は試験用の応答へ差し替えるため、実モデルの口調や応答品質の確認とは区別する。実接続は、利用者のAPIキーを画面に入力して確認する。テストはキーの保存同意、撤回、人格別の設定・履歴、再読み込み、送信内容、受信中断、再送、エラー表示、書き出しを対象にする。

OpenRouterの仕様は [Chat Completions](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion) と [Streaming](https://openrouter.ai/docs/api_reference/streaming) を参照。
