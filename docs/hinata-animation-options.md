# ひなたのアニメーション基盤

調査・実装日: 2026-10-29。現行ローカル版20261029-r11はPixiJS 8.22.0のMeshPlaneで、顔・胴体、表情、衣装、両腕、前後左右の髪を9メッシュに分けて動かす。腕は肩・肘・手首の3関節、髪は根元を頭に固定した変形とばねの追従を使う。顔は首・胴体とつながった絵のまま傾け、表情は位置合わせした6枚の差分を顔の内側だけで切り替える。CubismとSpineは公式ドキュメントの調査のみで、専用モデルの制作・実行は行っていない。

会話相手としての表情や顔の向きを充実させるなら、Live2D公式の **Cubism SDK for Web** を第一候補とする。SDKには瞬き、呼吸、口の動き、物理演算、表情・モーションを扱う仕組みがある。モデルはCubism Editorで制作・書き出しする。今ある一枚のWebPを読み込むだけでは、専用モデルにはならない。[公式SDKマニュアル](https://docs.live2d.com/en/cubism-sdk-manual/top/)、[公式Webサンプル](https://github.com/Live2D/CubismWebSamples)

| 候補 | このサイトでの用途 | 必要な準備 |
| --- | --- | --- |
| Live2D Cubism SDK for Web | 顔の向き、瞬き、口、髪などを個別に動かす会話用モデル | パーツ分けした絵を用意してモデルを制作し、`.moc3`、`.model3.json`、テクスチャ等を書き出す |
| PixiJS（採用済み） | メッシュ変形、腕の関節、髪の揺れ、表情差分を組み合わせる | パーツと整合する表情素材を用意し、関節と変形範囲を実装する。自動でLive2Dモデルを作る機能ではない |
| Spine + 公式spine-pixi | ボーンを使った全身のポーズや、まとまった動作の再生 | Spineで骨格とアニメーションを作り、`.json`または`.skel`、`.atlas`、画像を書き出す |

根拠: [Cubismのモデル読み込み](https://docs.live2d.com/en/cubism-sdk-manual/model-web/)、[PixiJS Mesh](https://pixijs.com/8.x/guides/components/scene-objects/mesh)、[spine-pixi公式ドキュメント](https://esotericsoftware.com/spine-pixi)。用途の順位は、このサイトの「キャラと向き合って会話する」目的に基づく判断。

Cubismを採用する場合は、ひなたの髪・目・口・顔・身体を分けてモデル化し、顔の左右・上下、傾き、目の開閉、口の開閉を調整する。その後、会話の待機・受信・終了、ドラッグ、なでる操作をモデルのパラメーターへ接続する。専用モデルが未取得・読み込み失敗の場合は、今の立ち絵へ戻す構成がよい。Coreの配布条件とSDKの利用条件は、組み込む版と公開方法に合わせて確認する。

顔の不整合を避けるため、目・口を別パーツにしない。顔全体を剛体として回転させ、首の部分だけ滑らかに胴体へつなぐ。腕は連続したメッシュを関節に追従させ、肩を袖の下へ重ねる。胴体の下端は[フィルター](https://pixijs.com/8.x/guides/components/filters)で透過させる。ライブラリと素材はサイト内に同梱し、閲覧時に外部CDNや画像生成APIを呼ばない。

現在のリグは正面絵の2Dアニメーション。横顔が見えるような立体的な振り向きや音声リップシンクは含まない。Cubismへ移行する場合は、正確なパーツと専用モデルの制作・調整が引き続き必要。


20261029-r10では、r9の見た目の合格判定を撤回し、曲げた肘を描いた腕の素材へ置き換えた。描いたポーズを基準に肩・肘・手首へ小さな回転を加える。顔・髪の素材は継続使用する。7メッシュ・7531頂点。待機と中間姿勢を含む比較画面と、実際の肌の画素を対象にする回帰検査を用意した。
